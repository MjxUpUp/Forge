# 验收 — {{title}}

`forge change verify` 按顺序执行下面的 ```bash 围栏：**一个围栏一条命令**（多步用 `&&` 串起来），
任意一条退出码非 0 即失败并停止。围栏内以 `set -e` 执行——中间步骤失败不会因为末条成功被吞掉。

写不成命令的验收不是判据，只是愿望。请拆成可观察信号：退出码、输出里的关键字、产物文件是否存在。

## 可执行判据

```bash
go build ./...
```

```bash
go test ./internal/...
```

## 人工检查项

人工项只展示、不计入封印：verify 通过不代表人工项已确认，人工项没确认也不影响封印。
它存在的意义是把"机器判不了、但人该看一眼"的东西摆到台面上，而不是当通过依据。
