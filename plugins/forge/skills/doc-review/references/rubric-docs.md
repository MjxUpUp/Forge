# 文档产物 L2 rubric（模型可判档位）

> **定位**：文档可读性三层约束的 L2 层。L1（`forge docs lint`，D1-D7）管机器可判的结构/禁令/枚举/篇幅；本 rubric 管 L1 判不了的「重点是否前置、详略是否得当、受众是否匹配」。L3（业务价值、对外措辞）不假装能自动化——模板显式标「需人工确认」。
>
> **适用**：PR 描述、commit body、测试报告、复盘报告，以及任务产出的任何给人即时阅读的文档。落盘 .md 先过 L1 再评分；PR/commit 不落盘，直接本表。

## 评分纪律（防作弊，先读这个再打分）

1. **产出者不能当回检者**：文档作者（含产出该文档的同一 agent 会话）不做最终评分——模型对自身输出有系统性偏好（偏好来自训练信号，换上下文不清除），「自查一遍」大概率回没问题。派独立子代理评审
2. **对抗立场**：默认假设「有问题，找出来」，不是「确认没问题」
3. **每条发现必须可证伪**：引用文档具体行（`L12`），禁止 `整体良好` 式无证据结论（该短语本身在 L1 禁令清单）
4. **改进建议给 delete-list**：删哪句/哪段/压成几行，不给「建议精简」——否则评审本身就是新一轮冗长
5. **轮次收敛**：L1 全过 + 总分 ≥75 + 零 Critical 未决 → 放行；3 轮仍 <75 → 升级人工确认，不无限打磨

## 通用四维（各 0-25，总分 100，阈值 75）

### 维度 1：结论前置 conclusion-first（0-25）

读者最关心的东西在第几行。

| 档位 | 判据 |
|------|------|
| 0 | 读完 1/3 还不知道结论/推荐/判定；开头是背景铺垫或定义罗列 |
| 10 | 结论在但埋在中段；或首行是「本文介绍了…」式目录话 |
| 20 | 首屏有结论但配套信息不全（判定有了，缺通过率/影响范围之一） |
| 25 | 第一行就是可执行结论（判定/推荐/GO·NO-GO），量化数据紧随，背景压到末尾或附录 |

### 维度 2：详略得当 detail proportion（0-25）

篇幅与信息量成正比。

| 档位 | 判据 |
|------|------|
| 0 | 大段复述 diff/源码/既有文档；或通篇填充话（`综上所述`、复述前文）凑长度 |
| 10 | 明细混在正文（失败输出全文、逐条日志），该下沉的不下沉 |
| 20 | 个别段落可压缩/合并同类项，删掉不影响决策的内容 <20% |
| 25 | 每段都有信息增量；明细全部下沉附录/链接；表格替代散文列举；删任何一段都会丢信息 |

### 维度 3：证据支撑 evidence（0-25）

断言是否可追溯。

| 档位 | 判据 |
|------|------|
| 0 | 通过/正常/无风险类断言零证据；或证据是「应该」「看起来」类主观推断 |
| 10 | 部分关键断言带证据，通过性断言（测试/验证/回归通过）至少一条无指针 |
| 20 | 关键断言均有指针（命令+结果、file:line、issue、百分比），次要断言个别裸奔 |
| 25 | 每个事实断言可点击/可复跑；数字全部有出处；「待确认」显式标注而非混入断言 |

### 维度 4：受众匹配 audience match（0-25）

写给谁看就用谁的语言。

| 档位 | 判据 |
|------|------|
| 0 | 对外文档满篇内部术语/代号无解释；或对内文档解释团队常识 |
| 10 | 术语偶有裸奔；标题堆砌/为格式加格式（没人要求的 P0/P1/P2 排序、空表格） |
| 20 | 语言基本匹配，个别段落视角漂移（给用户的部分写成了给评审的） |
| 25 | 术语首次出现即定义或链接；粒度按读者决策需要裁剪；无格式表演 |

## 类型特化判据（在通用四维之上叠加）

| 类型 | Critical（任一命中即阻断，且计入未决 findings） | 特有 25 分锚点（维度 1/2 达满档的标志） |
|------|------|------|
| PR 描述 | 无动机段（只有"改了 X"）；验证段无实跑命令 | 三段齐全且验证段可复制执行；破坏性变更首条 |
| commit body | 标题扫读无法定位变更；body 复述 diff 行 | 标题 ≤50 字符定位准确；body 只写 diff 外信息 |
| 测试报告 | 结论非枚举值；用例结果无证据列 | 首行判定+通过率；用例全表格化带证据指针 |
| 复盘报告 | 无根因（只有现象罗列）；行动项无负责人/截止 | 时间线带证据；根因到机制层；行动项表格化 |
| 其余类型（tech-plan/release-notes 等） | v1 仅通用四维兜底，无类型特化行 | 同类打回 ≥3 次再扩特化行（见 session-retrospective 的进化判据） |

## 与 L1/L3 的边界

- L1 能机器判的不占评分维度：禁令短语、必填章节、结论枚举、篇幅上限——命中直接打回修，不进 rubric 分数
- L3 不评：业务价值判断、对外措辞的政治敏感度——模板标「需人工确认」字段，评分时跳过
- 评审报告自身受同样约束：分级（Critical/Important/Minor）、每条带行号、给 delete-list——评审冗长即评审不合格
